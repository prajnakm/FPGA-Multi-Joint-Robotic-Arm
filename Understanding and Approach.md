# Introduction

This project presents the design and implementation of an FPGA-Based Multi-Joint Robotic Arm Control System using Verilog Hardware Description Language (HDL) on the Nexys-4 FPGA Development Board. The primary objective was to investigate how different types of motors respond to FPGA-generated control signals and to apply this knowledge to develop a coordinated three-joint robotic arm.

Rather than directly implementing the robotic arm, the project follows a systematic engineering approach where each stage is individually designed, tested, and experimentally validated. This methodology provides a clear understanding of motor control using FPGA technology while ensuring that every subsystem performs as expected before system integration.

# Why FPGA?

Most robotic systems are controlled using microcontrollers or microprocessors, which execute instructions sequentially. As the complexity of a robotic system increases, controlling multiple motors simultaneously while maintaining precise timing becomes increasingly challenging.

An FPGA (Field Programmable Gate Array) offers an alternative hardware-oriented approach where multiple modules operate in parallel. This enables precise timing, deterministic execution, and simultaneous generation of multiple control signals without processor scheduling delays.

# Key advantages of FPGA include:

Hardware-level parallel processing
Deterministic real-time execution
High-speed PWM generation
Simultaneous multi-motor control
Reconfigurable digital hardware
Reduced software overhead

These characteristics make FPGA an excellent platform for robotic motion control applications.

# Project Motivation

Robotic manipulators employ different types of actuators depending on application requirements. DC motors are widely used for continuous rotation, geared DC motors provide higher torque at reduced speed, while servo motors enable precise angular positioning.

Instead of immediately controlling servo motors, this project first investigates the behaviour of DC motors and geared DC motors under FPGA-generated PWM signals. Understanding how duty cycle influences motor performance establishes a strong foundation before implementing accurate position control of servo motors in a robotic arm.

# Project Development Strategy

The project was completed through five progressive stages.

## Stage 1 – PWM Generator

1.The first stage involved designing a Pulse Width Modulation (PWM) generator using Verilog HDL.<br>
2.PWM is a digital technique where the average voltage supplied to a motor is controlled by varying the ON time of a periodic signal while maintaining a constant switching frequency.<br>
3.The generated PWM forms the basis for controlling both motor speed and servo position.

## Stage 2 – PWM Verification

1.Before connecting any motors, the PWM generator was verified using the onboard LEDs available on the Nexys-4 FPGA board.<br>
2.Different duty-cycle values produced different LED brightness levels.<br>
3.This simple experiment confirmed that the PWM module was functioning correctly before hardware integration with motors.

## Stage 3 – DC Motor Control

The PWM signal was then interfaced with a conventional DC motor through an L293D H-Bridge Motor Driver.

# The objectives were to study:

1.Motor speed variation<br>
2.Effect of duty cycle<br>
3.Startup characteristics<br>
4.Smoothness of operation<br>

The experiments confirmed that increasing the duty cycle increased the average voltage supplied to the motor, resulting in higher rotational speed.

## Stage 4 – DC Geared Motor Analysis

1.The same PWM controller was then tested using a DC geared motor.<br>
2.Unlike a conventional DC motor, the geared motor incorporates an internal gearbox that reduces speed while increasing output torque.

# Experimental observations showed:

1.Lower rotational speed<br>
2.Higher torque<br>
3.Better load-handling capability<br>
4.Stable response to PWM variation<br>

This comparison demonstrated why geared motors are preferred in robotic mechanisms requiring higher torque.

## Stage 5 – Servo Motor Calibration

1.Unlike DC motors, servo motors do not operate based on duty cycle alone.<br>
2.Servo motors require a fixed repetition period (approximately 20 ms), while the pulse width determines the desired angular position.<br>
3.Since practical servo motors exhibit manufacturing variations, the SG5010 servos used in this project were experimentally calibrated to obtain accurate pulse widths corresponding to different joint angles.<br>
4.The calibrated values were then used for robotic arm implementation.

# Three-Joint Robotic Arm

Three SG5010 servo motors were used to construct the robotic arm.<br>

The joints include:<br>
1.Shoulder<br>
2.Elbow<br>
3.Wrist<br>

Each joint receives an independent PWM signal generated by the FPGA.<br>

Different switch combinations correspond to predefined robotic arm poses, allowing repeatable movement between multiple positions.<br>

# Motion Control Algorithm

To coordinate the robotic arm movement, a Finite State Machine (FSM) was implemented in Verilog HDL.<br>

The movement sequence is:<br>

1.Home Position<br>
2.Move Shoulder<br>
3.Move Elbow and Wrist Simultaneously<br>
4.Hold Position<br>
5.Return to Home<br>

This sequencing prevents abrupt joint motion and provides smooth, coordinated operation.<br>
