# FPGA-Multi-Joint-Robotic-Arm
FPGA-based multi-joint robotic arm control system implemented using Verilog HDL on the Nexys-4 FPGA. Features PWM-based DC and SG5010 servo motor control, FSM-based motion sequencing, L293D motor driver integration, and coordinated shoulder, elbow, and wrist movement for real-time robotic applications.
